# 🚀 Enterprise Playwright E2E & API Test Automation Framework

An enterprise-grade test automation framework built with **Playwright**, **TypeScript**, and **Page Object Model (POM)** architecture.

## 🛠️ Tech Stack
* **Engine:** Playwright Test
* **Language:** TypeScript
* **Reporting:** Allure Report & Custom Lifecycle Reporter
* **CI/CD:** GitHub Actions Matrix Execution
* **Database:** SQLite / Data Integrity Verification

## 📂 Project Structure
* `pages/` - Page Object Model classes
* `fixtures/` - Custom fixtures & dependency injection
* `tests/e2e/` - End-to-End user flow test suites
* `tests/api/` - Backend API validation suites
* `utils/` - Database client & environment utilities
